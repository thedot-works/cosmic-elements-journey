# Cosmic Elements Journey — How Old Is Gold?

A single-page, interactive cosmic experience: a ~15-second cinematic
introduction plays automatically inside a persistent 3D star field, then
seamlessly becomes a hands-on "Cosmic Forge" where **you are the universe** —
selecting cosmic objects, combining them, and discovering how the elements
(culminating in Gold) were actually built.

There are no separate slides, pages, or scene cuts. One environment, one
continuous journey, driven internally by a state machine
(`INTRO → LAB → EXPERIMENT / MERGER → GOLD_JOURNEY → back to LAB`).

## Run it

This is a fully static site — no build step, no server-side code.

```bash
# from the project root
python3 -m http.server 8000
# then open http://localhost:8000/
```

Or just open `index.html` directly in a modern desktop browser (Chrome,
Edge, Firefox, Safari). It also works fine served from GitHub Pages —
push this repo and enable Pages on the `main` branch / root folder.

No API keys, no dependencies to install, no bundler. `js/vendor/three.min.js`
(Three.js r128) is vendored directly in the repo so the page works fully
offline and doesn't depend on any third-party CDN being reachable.

## How it works

- **Intro** (`js/intro.js`) — the ~13–15s autoplay cinematic: Big Bang →
  first elements → periodic table teaser → "You Are The Universe." Skippable
  at any time via the button in the bottom-right corner.
- **Cosmic Forge / Lab** (`js/lab.js`) — the persistent sandbox. Pick a
  target element (Gold by default), drag cosmic objects into Slot A / Slot
  B, and press **Activate** (or **Merge**, for the neutron-star pair).
- **Experiments** (`js/experiments.js`) — single-object / mismatched-pair
  visualizations: stellar fusion, a massive star's onion-shell burning and
  supernova, a magnetar (flagged as active research), a quiet white dwarf,
  interstellar gas recycling, and a generic "you made something, but not
  that" path for combinations that don't have a real physical relationship.
- **Merger** (`js/merger.js`) — the visual centerpiece: two neutron stars
  spiral in, gravitational waves ripple a spacetime grid, they collide in a
  kilonova, and you choose what to inspect. Following the ejecta triggers
  **the great scale zoom** (kilometres → atoms → femtometre nuclei) and an
  interactive **r-process** mini-simulation — rapid neutron capture and beta
  decay climbing the atomic number chart, ending on your target element.
- **Gold Journey** (`js/gold-journey.js`) — only for Gold: the freshly-made
  nucleus rides the kilonova ejecta through millions of years, seeds a
  molecular cloud, collapses into a new star and protoplanetary disk, and
  ends up in the Earth that forms 4.6 billion years later. Answers the
  title question ("gold on Earth predates Earth itself") and closes with
  the ring-on-a-hand payoff before zooming back out to the whole galaxy.
- **Periodic table discovery map** (`js/periodic-table.js`) — a real
  118-element table (`js/elements-data.js`, generated by
  `scripts/gen_elements.js`) that starts almost entirely dark and lights up
  as you make real discoveries, with hover tooltips explaining *why* each
  element exists.
- **Persistent 3D environment** (`js/starfield.js`) — one Three.js scene,
  never torn down: parallax starfield, soft nebula, camera fly-tos, and a
  small reusable toolkit (particle bursts, an orbiting-pair generator, a
  rippling spacetime grid, a molecular-cloud collapse) shared by every
  state above.

## Science notes baked into the design

- Big Bang nucleosynthesis is depicted as producing only H, He, and trace
  Li — nothing else.
- Ordinary stellar fusion is capped realistically: energy-releasing fusion
  doesn't simply continue past the iron-group region.
- Gold (and other very heavy elements) are only produced through the
  **r-process** — rapid neutron capture — which the experience ties to
  neutron-star mergers, a confirmed astrophysical site for it.
- Magnetars are explicitly labeled as an *active area of research*, not a
  confirmed pathway.
- The nuclear climb from iron to gold is shown as a walk through many
  unstable isotopes (with a few recognizable milestones — Hf, W, Pt) rather
  than a false simple "Fe → Ag → Pt → Au" staircase.
- The closing narration is careful not to assign gold atoms a single exact
  age — only that they predate the Earth.
- A **Story / Science** toggle (top-right) overlays additional technical
  labels (masses, distances, isotope/decay detail) on the same visuals
  without ever becoming a separate page.

## Project structure

```
index.html              Single entry point / page shell
css/main.css             All styling (deep-space theme, overlays, periodic table, responsive)
js/elements-data.js      Generated 118-element dataset (see scripts/gen_elements.js)
js/starfield.js          Persistent Three.js scene + reusable visual toolkit
js/periodic-table.js     Periodic table rendering + discovery state
js/audio.js              Minimal, muted-by-default ambient cinematic audio
js/intro.js              Autoplay cinematic intro sequence
js/lab.js                Cosmic Forge interaction: objects, targets, hints, combos
js/experiments.js        Single-object / wrong-combination full-screen visualizations
js/merger.js             Neutron-star merger, kilonova, scale zoom, r-process, reveal
js/gold-journey.js       Gold's journey to Earth + closing sequence
js/app.js                Boot + top-level state wiring
js/vendor/three.min.js   Vendored Three.js r128 (no external CDN dependency)
scripts/gen_elements.js  Regenerates js/elements-data.js
```

## Browser support / performance

Targets desktop Chrome/Edge/Firefox/Safari. Particle counts are kept modest
(GPU-friendly point sprites, no per-particle physics) so it should run
smoothly on integrated graphics. On very small/low-power devices the object
library and slightly detailed panels are hidden via a responsive breakpoint
to keep the core experience usable; the desktop experience is the primary
target described in the design brief.
